# 3D 에셋 생성 프롬프트북 — 세이프 키친 (실사용 확정본)

기획서·포트폴리오·공모전 AI 활용 문서에 그대로 인용 가능한 원문 기록.

## 파이프라인

1. **Google 제미나이(나노바나나)**: 아래 프롬프트로 컨셉 이미지 생성 (흰 배경 단일 오브젝트)
2. **Tripo AI** (image-to-model API): 이미지 → 텍스처 포함 GLB 변환
3. **Unity 자동 배치**: Claude가 임포트·스케일·씬 배치·상호작용 연결
4. 캐릭터는 Tripo 웹에서 리깅+애니메이션 후 FBX 내보내기 (§4)

## 공통 스타일 문구 (확정판 — 모든 프롬프트 끝에 결합)

> 단일 오브젝트, 순수 흰색 배경, 3/4 등각 뷰(약간 위에서), 오버쿡 게임 스타일의
> 청키한 로우폴리 카툰, 통통하고 둥근 비율, 밝고 쨍한 파스텔 색, 그림자 없음.

영문판 (제미나이 영어 모드용):
> Single object, pure white background, 3/4 isometric view from slightly above,
> Overcooked-game-style chunky low-poly cartoon, plump rounded proportions,
> bright cheerful pastel colors, no shadows.

## §1 주방 기본 세트

- **기본 조리대 블록**: 정육면체에 가까운 통통한 주방 조리대 블록 하나. 민트색 몸체, 크림색 두꺼운 상판, 앞면에 둥근 여닫이 문 2개와 작은 손잡이. + 공통
- **2칸 조리대**: 가로로 긴 통통한 주방 조리대 블록 하나, 폭이 높이의 2배인 직육면체. 민트색 몸체, 크림색 두꺼운 상판, 앞면에 둥근 여닫이 문 4개가 나란히, 작은 손잡이. + 공통
- **가스레인지 스테이션**: 통통한 주방 조리대 블록인데 상판이 짙은 남색 가스레인지. 동그란 화구 2개와 노란 점화 손잡이, 몸체는 민트색. + 공통
- **가스레인지 일체형 조리대**: 가로로 긴 통통한 주방 조리대 블록 하나, 폭이 높이의 2배인 직육면체. 민트색 몸체, 크림색 상판인데 오른쪽 절반은 짙은 남색 가스레인지 상판 — 동그란 화구 2개와 은색 삼발이, 앞면에 노란 점화 손잡이 2개. 왼쪽 절반은 빈 조리 공간. + 공통
- **싱크 스테이션**: 통통한 주방 조리대 블록인데 상판에 은색 싱크볼과 높이 솟은 귀여운 수도꼭지. 몸체는 민트색, 상판은 크림색. + 공통
- **대형 솥**: 통통하고 둥근 대형 은색 솥, 양쪽에 손잡이, 뚜껑 없음. + 공통
- **냉장고**: 통통하고 키가 약간 큰 냉장고, 흰색 몸체에 민트색 문, 둥근 은색 손잡이 2개. + 공통
- **소화기**: 통통하고 귀여운 빨간 소화기, 검은 호스와 노란 안전핀. + 공통
  - (영문 텍스트 다이렉트판) cute chunky fire extinguisher, bright red rounded body, small black hose on the side, yellow safety pin handle + 영문 공통
- **재료 상자**: 나무 크레이트 상자에 토마토와 양파가 소복이 담긴 모습. + 공통

## §2 확장 세트 (레이아웃 개편 후)

- **긴 서랍장(8문)**: 가로로 아주 긴 통통한 주방 조리대 하나, 폭이 높이의 5배인 낮고 긴 직육면체. 민트색 몸체, 크림색 두꺼운 상판, 정면에 둥근 여닫이 문 8개가 나란히 달려 있고 각 문에 작은 크림색 손잡이. 정면이 잘 보이는 살짝 위에서 본 뷰 + 공통
- **빌트인 일체형 조리대** (화구+싱크 매립 — 북쪽 라인 최종형): 가로로 아주 긴 통통한 주방 조리대 하나, 폭이 높이의 5배인 낮고 긴 직육면체. 민트색 몸체, 크림색 두꺼운 상판. 상판 왼쪽에는 짙은 남색 가스레인지가 빌트인으로 매립되어 동그란 화구 2개와 은색 삼발이가 있고, 그 아래 앞면에 노란 점화 손잡이 2개. 상판 오른쪽에는 은색 싱크볼이 매립되어 있고 위로 굽은 수도꼭지가 솟아 있음. 가운데 상판은 빈 조리 공간. 앞면에는 둥근 여닫이 문 4개와 작은 크림색 손잡이. 정면이 잘 보이는 살짝 위에서 본 뷰 + 공통 ※ 16:9 가로형으로 생성
- **레인지 후드**: 주방 벽에 붙는 레인지 후드 하나. 아래는 넓게 벌어진 사다리꼴 갓, 위로 통통한 사각 굴뚝이 솟아 있음. 갓은 짙은 남색, 굴뚝은 민트색, 갓 테두리에 크림색 라인, 앞면에 동그란 작은 버튼 2개. 정면이 잘 보이는 살짝 위에서 본 뷰 + 공통
- **닫힌 창문**: 벽에 끼우는 통통한 여닫이 창문 블록, 완전히 닫힌 상태. 크림색 두꺼운 창틀, 하늘색 유리 2칸이 나란히, 유리에 살짝 광택. 정면이 잘 보이는 뷰 + 공통
- **열린 창문(반개)**: 벽에 끼우는 통통한 여닫이 창문 블록, 하늘색 유리 2칸, 크림색 창틀, 반쯤 열린 모습. + 공통
- **빈 창틀**: 창짝이 없는 빈 여닫이 창문 틀만. 크림색 두꺼운 창틀, 통통한 직사각형. 정면 뷰 + 공통
- **창짝 한 장**: 창문의 창짝 한 장만. 하늘색 유리 2칸에 크림색 얇은 살, 통통한 직사각형 판. 정면 뷰 + 공통
- **지진 대피 테이블 (최종형)**: 어른 허리 높이의 튼튼한 주방 식탁 하나. 넓고 납작한 크림색 상판(두께는 얇게), 모서리에 길고 굵은 민트색 다리 4개. 다리 길이가 상판 두께의 4배 이상이라 아래 공간이 높고 넓게 뚫려 있어 사람이 기어들어가 숨을 수 있는 대피 공간처럼 보임. 가로가 세로보다 긴 직사각 식탁. 정면이 잘 보이는 살짝 위에서 본 뷰 + 공통
  - (1차 시안 — 의자처럼 나와 폐기): 튼튼한 주방 대피용 테이블 하나. 두껍고 둥근 크림색 상판, 굵고 튼튼한 민트색 다리 4개, 다리 사이 아래 공간이 넓게 뚫려 있어 사람이 들어가 숨을 수 있어 보임. + 공통
- **주방 의자**: 귀여운 주방 의자 하나. 크림색 둥근 방석 시트, 민트색 굵은 다리 4개, 뒤에 낮고 둥근 민트색 등받이. 정면이 잘 보이는 살짝 위에서 본 뷰 + 공통

## §3 가스안전 소품

- **밸브 몸체 (최종형)**: 한국 가정용 가스 중간밸브(볼밸브)의 몸체만, 레버 손잡이는 뺀 상태. 황동색 둥근 몸체, 몸체 위에 레버를 눕혀 끼우는 낮은 육각 너트와 짧은 축, 양옆으로 은색 배관이 일직선으로 짧게 뻗음. + 공통
  - (1차 시안): 가스 배관에 달린 한국식 중간밸브의 몸체만, 레버 손잡이는 없는 상태. 황동색 둥근 밸브 몸체, 위에 레버 꽂는 짧은 축, 양옆으로 은색 배관이 짧게 뻗어 있음. + 공통
- **레버 손잡이 (최종형 — 실물 사진 참조 후 재생성)**: 가스 중간밸브의 빨간 레버 손잡이 한 개만. 납작하고 길쭉한 판 모양으로 수평으로 눕혀진 형태, 축에 끼우는 쪽은 둥근 구멍이 있고 반대쪽 끝은 살짝 위로 들리며 둥글게 마감. 위에서 잡고 90도 돌리는 손잡이. + 공통
  - (1차 시안 — 샛노랑, 실물과 달라 폐기): 가스밸브의 샛노란 레버 손잡이 한 개만. 길쭉하고 통통한 막대 모양, 한쪽 끝에 축에 끼우는 둥근 구멍 부분, 끝이 둥글게 마감됨. + 공통
- **직선 파이프**: 은색 가스 배관 직선 파이프 한 토막, 양 끝에 둥근 이음쇠 링. + 공통
- **ㄱ자 엘보**: 은색 가스 배관의 ㄱ자로 꺾인 엘보 파이프 한 개, 양 끝에 둥근 이음쇠 링. + 공통
- **벽 고정 클램프**: 파이프를 벽에 고정하는 작은 은색 반원 클램프 브래킷 한 개, 나사 2개. 정면 뷰 + 공통

## §4 캐릭터 — KGS 공식 '가스레인저' (사용 허가: 공모전 FAQ 2026-08-18, 스크린샷 증빙)

**자세 규칙 (3D 변환 품질의 절반):** 정면 응시 전신, 차렷에 가까운 A포즈, 양팔은 몸통에서 살짝 벌림(붙으면 3D에서 융합), 다리 어깨너비 대칭, 소품 금지, 망토는 차분히. 역동 포즈·팔짱·몸 가리는 손 금지.

**나노바나나 자세 보정 (공식 일러스트 첨부 후):**
> 이 캐릭터의 생김새, 색, 비율, 디자인을 그대로 유지해서 다시 그려줘. 전신이
> 발끝까지 다 보이게, 정면을 바라보는 차렷에 가까운 자세. 양팔은 몸통에서 살짝
> 벌리고, 다리는 어깨너비, 좌우 대칭. 소품 없음, 순수 흰색 배경, 그림자 없음.

**3등신 비율 보정 (Tripo v3 이미지 편집 API, banana2 모델):**
> 같은 캐릭터의 디자인, 색, 안전모, 바이저, 그림체를 정확히 유지. 비율만 조정:
> 머리를 지금보다 작게 줄이고, 몸통과 팔다리를 더 길게 늘여서 3등신 비율의
> 전신으로. 정면을 보고 차렷에 가까운 자세, 양팔은 몸에서 살짝 벌림. 순수 흰색
> 배경, 그림자 없음, 전신이 발끝까지 보이게

**Tripo 웹 리깅·애니 내보내기 규약:** 리깅 모델에 애니 3종(달리기→걷기→대기 순) 적용, Mixamo 프리셋, 스켈레톤 ON, 내보내기 다이얼로그에서 애니메이션 수 확인(0이면 빈 파일!), 파일명 RangerRed.fbx 합본 1파일.
