# 세이프 키친 (Safe Kitchen) — 기획서 v0.4

한국가스안전공사 「가스안전 AI 게임·영상 공모전」 출품작 / 1인 개발 + AI 협업
v0.4 — 2026-08-29 (v0.3 대비: 랭크·일시정지·씬 3종·미니게임 확장·수료 기억·모듈 킷 반영)

## 1. 컨셉

오버쿡드 스타일 쿼터뷰 주방에서 KGS 공식 캐릭터 **가스레인저**가 되어
가스안전 행동요령을 몸으로 익히는 3D 교육 액션 게임.
"읽는 안전교육"이 아니라 "손이 기억하는 안전교육" — 밸브를 직접 잠그고, 소화기를 직접 쓸어본다.

- 대상: 초등 고학년~일반 (퀴즈는 어린이 눈높이, 조작은 전연령)
- 플랫폼: Windows PC (exe) / 플레이타임 1판 3~4분, 반복 랭크 도전형
- 시점: 원근 쿼터뷰 기본 + 1인칭 전환(V키) 지원

## 2. 게임 플로우

타이틀(씬 선택·배지 도감) → 소방학교 훈련(최초 1회, 수료 기억) → 본 게임 3단계 → 랭크 결산

| 단계 | 상황 | 배우는 행동요령 | 메커닉 |
|---|---|---|---|
| 소방학교 | 교관 체키의 훈련 | 소화기 사용법(PASS), 밸브 조작 | 대화 UI + 실습 게이트 |
| 일상 대처 | 주방 곳곳 위험 요소 | 빈 냄비 화재, 콘센트, 환기 등 | 물음표 접근 → 안전 퀴즈(칠판 UI) |
| 지진 1차 | 흔들림 + 화구 화재 | 흔들림 감지 즉시 불·밸브 차단, 잔불 진압 | 예고 연출 → 밸브 미니게임(연타→타이밍) → 소화기 조준·쓸기 |
| 지진 2차 | 가스 누출 | 불꽃 금지, 밸브 차단, 환기 | 밸브 연타 → 창문 열기 미니게임 → 비눗물 점검 |
| 결산 | 훈련 결과 | 복습 대사 | 칠판 랭크(S/A/B)·별·이번 판 배지 |

## 3. 핵심 재미 장치

- **밸브 미니게임**: 연타로 게이지 → 타이밍 링에 바늘 멈추기. 클로즈업 일러스트(KGS 가스 각인).
- **소화기**: 조준 부채꼴 + 마우스 쓸기 분사 — "빗자루 쓸듯" PASS의 S(Sweep)를 체화.
- **타격감**: 히트스톱·펀치줌·미니셰이크·래칫 틱 사운드.
- **배지 수집(6종)**: 수료·화재 진압·누출 대응·점검·콤보·퍼펙트. 타이틀 도감에 영구 전시.
- **랭크 반복**: S랭크(1100점+·아차 1 이하) 도전 구조. [R] 즉시 재도전.
- **아차 카운트**: 실패를 벌점이 아닌 "아차"로 부드럽게 집계 — 어린이 정서 배려.
